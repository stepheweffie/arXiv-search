# 🚀 arXiv Visual Search & Analytics

**Transform research discovery with AI-powered semantic search and stunning visualizations**

A comprehensive research discovery platform that combines arXiv paper search, transformer-based semantic analysis, and beautiful interactive visualizations. Explore 30+ years of academic research through natural language queries, ML-powered clustering, and professional data analytics.

## ✨ Key Features

🧠 **AI-Powered Semantic Search** - Query papers using natural language with 768-dimensional transformer embeddings  
📊 **Interactive Visual Analytics** - Publication trends, word clouds, and 2D embedding visualizations  
📚 **Complete Jupyter Book** - Professional documentation with executable notebooks  
🎯 **Multi-Dataset Support** - 1K papers (demo), 1.5K papers (visual), 3K+ papers (CLI)  
🔬 **Advanced ML Clustering** - 8 distinct research groups identified through K-means analysis  
📈 **Publication Trend Analysis** - Track research evolution from 1992-2025  

## 🎨 Visual Highlights

- **Publication Dashboard**: Multi-panel analytics with year trends and topic analysis
- **Semantic Search Demo**: 0.8+ similarity scores for relevant paper discovery  
- **Clustering Visualization**: Research groups mapped in 2D embedding space
- **Word Clouds**: Dynamic visualization of trending research keywords
- **Professional Charts**: Publication patterns with value labels and insights

## 🛠️ Technology Stack

- **AI/ML**: SentenceTransformers, UMAP, scikit-learn, K-means clustering
- **Visualization**: Matplotlib, Seaborn, Plotly, WordCloud  
- **Data Processing**: pandas, d6tflow workflow management
- **Documentation**: Jupyter Book with interactive notebooks
- **APIs**: arXiv API integration for real-time paper discovery
