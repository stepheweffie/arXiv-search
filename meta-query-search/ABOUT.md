# 🔍 arXiv Visual Search & Analytics

A comprehensive semantic search and analytics platform for arXiv research papers, powered by transformer embeddings and interactive visualizations.

## ✨ Key Features

- **🤖 Dual AI Models**: Compare SPECTER (scientific-specialized) vs Sentence-Transformers (general-purpose) embeddings
- **🔍 Semantic Search**: Query research papers using natural language across multiple AI domains
- **📊 Visual Analytics**: Interactive charts, similarity heatmaps, and publication trend analysis  
- **🧠 Cross-Domain Exploration**: Search consciousness, quantum machine learning, transfer learning, and more
- **📚 Live Documentation**: Comprehensive Jupyter Book with executable notebooks and real results
- **🚀 Modern Stack**: Built with transformers, sklearn, pandas, d6tflow, and Jupyter Book

## 🎯 What Makes It Special

- **Real Performance Comparison**: SPECTER achieves 0.823 avg similarity vs 0.541 for general models
- **Fresh Research**: Includes emerging topics like machine unlearning and quantum-AI intersection
- **Production Ready**: Complete pipeline from data ingestion to interactive search interface
- **Reproducible Science**: All results cached and version-controlled with detailed methodology

## 🔬 Research Domains Covered

Machine Learning • Natural Language Processing • Computer Vision • Reinforcement Learning • Quantum Computing • Consciousness Studies • Transformer Architectures • Privacy-Preserving AI

Perfect for researchers, data scientists, and AI practitioners exploring the semantic landscape of modern scientific literature.
